# Ланская — демо-лендинг косметолога

Одностраничный сайт частного косметолога: оффер с ценой на первом экране, прайс с
длительностью и восстановлением, «до/после» ползунком, отзывы, частые вопросы и запись
в Telegram или MAX. Мастер, отзывы и фото вымышлены — это демо для портфолио.

- Один `index.html` без сборки и библиотек: параллакс, появление блоков и строк
  заголовков написаны вручную, уважают `prefers-reduced-motion`.
- CSP в `<meta>` (GitHub Pages не даёт ставить заголовки), скрипты разрешены по хешу.
  Поправили скрипт — `python csp_hash.py`, иначе браузер молча его не запустит.
- Форма пока демо: проверяет поля и показывает ответ. Для живого сайта отправка
  уходит в Telegram-бот мастера; перед этим — согласие на обработку персональных
  данных и политика (152-ФЗ).

Публикуется workflow `.github/workflows/pages.yml`: наружу только `index.html` и `img/*.jpg`.
